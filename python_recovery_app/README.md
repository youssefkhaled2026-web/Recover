# برنامج استرجاع الملفات ومحادثات واتساب (وضع القراءة فقط)

برنامج Python مكتبي بواجهة رسومية (Tkinter) يعمل **محليًا 100%** بدون أي اتصال بالإنترنت وبوضع **القراءة فقط** على الأقراص وقواعد البيانات، لاسترجاع الملفات المحذوفة وتحليل نسخ واتساب الاحتياطية المشفرة (`crypt14` / `crypt15`).

## الملفات المكونة للمشروع
- `main.py` — نقطة التشغيل الرئيسية.
- `gui_app.py` — الواجهة الرسومية الكاملة (3 تبويبات: استرجاع الملفات، محادثات واتساب، فحص SQLite العميق).
- `config.py` — بصمات الملفات (Magic Bytes) وثوابت أنواع وحالات رسائل واتساب.
- `file_carver.py` — محرك فحص الأقراص/الصور/المجلدات بالبصمات وتقدير احتمالية الاسترجاع والحفظ في مجلد آمن.
- `whatsapp_decryptor.py` — فك تشفير `msgstore.db.crypt14` و `msgstore.db.crypt15` (مفتاح 64 رقمًا أو ملف `key`).
- `whatsapp_parser.py` — محلل قواعد بيانات واتساب الحديثة (`message`, `chat`, `jid`, `message_media`, `message_quoted`) والقديمة (`messages`).
- `sqlite_forensics.py` — محرك استرجاع السجلات المحذوفة من `Freelist Pages` و `B-Tree Freeblocks` وملفات `-wal`.
- `exporter.py` — تصدير المحادثات إلى `HTML` و `PDF` و `CSV`.
- `requirements.txt` — المكتبات المطلوبة.

## خطوات التشغيل خطوة بخطوة

1. **تثبيت Python 3.10+**: تأكد من تحديد خيار `Add Python to PATH` أثناء التثبيت على Windows.
2. **تثبيت المكتبات المطلوبة**:
   ```bash
   cd python_recovery_app
   pip install -r requirements.txt
   ```
3. **تشغيل البرنامج**:
   - للتشغيل العادي (فحص مجلدات، صور أقراص `.img`، أو فك تشفير نسخ واتساب):
     ```bash
     python main.py
     ```
   - لفحص قرص أو كارت ذاكرة خام على Windows (`\\.\E:` أو `\\.\PhysicalDrive1`): افتح موجه الأوامر **كمسؤول (Run as Administrator)** ثم شغّل `python main.py`.
4. **نسخ ملفات واتساب من هاتف Android عبر USB**:
   - وصّل الهاتف عبر USB واختر وضع **نقل الملفات (File Transfer / MTP)**.
   - انسخ مجلد النسخ الاحتياطية ومجلد الوسائط من أحد المسارين التاليين إلى مجلد آمن على جهازك:
     - في نسخ أندرويد الحديثة (Android 11+):
       `Internal Storage/Android/media/com.whatsapp/WhatsApp/Databases/` و `.../WhatsApp/Media/`
     - في النسخ الأقدم:
       `Internal Storage/WhatsApp/Databases/` و `.../WhatsApp/Media/`

## كيف تستخرج المفتاح من هاتفك الشخصي (بطرق مشروعة لهاتفك فقط)

### 1) لنسخ `crypt15` (الطريقة الأسهل والرسمية بدون صلاحيات Root)
1. افتح **واتساب** على هاتفك الشخصي -> **الإعدادات (Settings)** -> **الدردشات (Chats)**.
2. اختر **النسخ الاحتياطي للدردشات (Chat backup)** -> **النسخ الاحتياطي المشفر تمامًا بين الطرفين (End-to-end encrypted backup)**.
3. اختر **تغيير مفتاح التشفير (Change encryption key)** أو **استخدام مفتاح تشفير مكون من 64 رقمًا (Use 64-digit encryption key)**.
4. احفظ المفتاح المكون من **64 خانة (أرقام وحروف a-f)** وأدخله في البرنامج، ثم أنشئ نسخة احتياطية محلية جديدة (أو استخدم النسخة المرتبطة بنفس المفتاح).

### 2) لنسخ `crypt14` (ملف `key`)
- في حال كان هاتفك الشخصي مملوكًا لك ومفعّل عليه صلاحيات الوصول الكاملة للنظام (Root)، يُحفظ ملف المفتاح في المسار المحمي:
  `/data/data/com.whatsapp/files/key`
  (وفي الأجهزة غير المروتة يمنع أندرويد الوصول إلى `/data/data/` لحماية خصوصية التطبيقات، ولذلك يُنصح بالاعتماد على مفتاح الـ 64 رقمًا لـ `crypt15`).

## حدود الاسترجاع (متى يكون الاسترجاع مستحيلًا؟)

1. **الكتابة فوق القطاعات (Overwritten Data)**: إذا خُزّنت بيانات جديدة فوق نفس قطاعات الملف المحذوف، تصبح البيانات الأصلية مفقودة نهائيًا.
2. **أمر TRIM في أقراص SSD وذاكرة الهاتف الداخلية (UFS/eMMC)**: معظم أقراص SSD الحديثة وذاكرة الهواتف تنفّذ TRIM/Discard فور الحذف، فتُصفّر القطاعات فيزيائيًا وتصبح غير قابلة للاسترجاع.
3. **تشفير الملفات في أندرويد (File-Based Encryption - FBE)**: منذ Android 7+، يُشفَّر كل ملف بمفتاح مستقل؛ وعند حذف الملف يُتلف مفتاحه، ما يجعل الاسترجاع الخام من ذاكرة الهاتف الداخلية غير ممكن بدون نسخة احتياطية أو مفتاح التشفير.
4. **محدودية بروتوكول USB MTP**: عند توصيل هاتف Android بالكمبيوتر عبر USB، يعرض الهاتف نظام ملفات افتراضيًا (MTP) لا يسمح بالوصول لقطاعات القرص الخام (`Raw Block Device`)، لذا فإن File Carving على مستوى القطاعات يعمل على **كروت الذاكرة الخارجية SD عبر قارئ كروت**، أو **الفلاشات**، أو **صور الأقراص (`.img`/`.dd`)**.
5. **محادثات واتساب المحذوفة قديمًا**:
   - إذا حذف المرسل رسالة ("الحذف لدى الجميع") قبل أخذ النسخة الاحتياطية، قد لا يحتوي الحقل النصي على النص الأصلي (يظهر نوع الرسالة `15`).
   - إذا نفّذ واتساب عملية `VACUUM` لقاعدة بيانات SQLite أو أُعيد استخدام صفحات `Freelist`، تختفي بقايا السجلات المحذوفة من الصفحات الحرة نهائيًا.
6. **فقدان المفتاح**: بدون ملف `key` الصحيح أو مفتاح الـ 64 رقمًا المطابق لنسخة `crypt14`/`crypt15`، لا يمكن فك تشفير AES-256-GCM رياضيًا.
